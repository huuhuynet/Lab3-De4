# Wokwi

Lưu các tệp phục vụ mô phỏng mạch Wokwi.

- `diagram.json`: sơ đồ linh kiện và kết nối.
- `libraries.txt`: danh sách thư viện Arduino cần cài (nếu sử dụng).
- `wokwi-project.txt`: lưu liên kết dự án Wokwi.

Sau khi tạo mô phỏng, cập nhật liên kết trong `wokwi-project.txt` và README ở thư mục gốc.
