# Website

Đặt mã nguồn giao diện Website tại đây.

- `index.html`: cấu trúc trang và hai thẻ hiển thị số liệu.
- `style.css`: định dạng giao diện.
- `script.js`: kết nối MQTT qua WebSocket, cập nhật dữ liệu,
  biểu đồ và gửi lệnh điều khiển.

Website và ESP32 phải thống nhất Broker, cổng WebSocket và topic.
Không lưu thông tin bí mật trong mã nguồn công khai.
